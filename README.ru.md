# X-Announcer для X-Plane 12

Аналог [MSFS Universal Announcer](https://github.com/fearlessfrog/MSFS_Universal_Announcer)
для X-Plane 12: скрипт FlyWithLua, который сам следит за фазой полёта и играет
объявления бортпроводников — посадка пассажиров, музыка на борту, брифинг по
безопасности, «пристегните ремни», снижение, высадка.

Главное: **звуковые паки те же самые**. Никакой конвертации — папки с кодом
авиакомпании, файлы `.ogg` с именами событий и тегами в квадратных скобках
читаются как есть. Тот же формат используют наборы для Fenix. Если у вас уже
есть библиотека от MSFS-версии (например `D:\UA_Sounds`), скрипт найдёт её сам
при первом запуске.

> **Где взять паки.** Их раздают в Discord сообщества Universal Announcer —
> <https://discord.com/invite/P8ZYJgH3ZF>. В этом репозитории только плагин:
> звук не мой, чтобы его распространять.

## Требования

| Что | Версия |
|---|---|
| X-Plane | 12 |
| [FlyWithLua NG+](https://forums.x-plane.org/index.php?/files/file/82888-flywithlua-ng-next-generation-plus-edition-for-x-plane-12-win-lin-mac/) | **2.8.9 и новее** (нужен FMOD-звук) |
| curl | только для необязательного запроса в SimBrief; есть в Windows 10+, macOS и Linux, а если его нет — подменяется PowerShell (Windows) или wget (остальные) |

Звук идёт через собственный FMOD X-Plane, поэтому играются `.ogg`, `.wav`,
`.mp3` и `.flac` без внешних кодеков, а громкость подчиняется звуковым
настройкам симулятора.

## Установка

Скопировать в папку скриптов FlyWithLua:

```
X-Plane 12/Resources/plugins/FlyWithLua/Scripts/
├── x_announcer.lua
└── x_announcer/
    ├── airlines.lua      (справочник авиакомпаний, нужен для автоопределения)
    ├── spravka-ru.txt    (справка по окну и словарик подписей)
    ├── readme-en.txt     (то же по-английски)
    └── config.ini        (создастся сам, все настройки описаны внутри по-русски)
```

Затем в X-Plane: **Plugins → FlyWithLua → FlyWithLua Macros → X-Announcer
Control Panel**. Это единственное меню, которое FlyWithLua даёт скриптам:
своего пункта в меню Plugins скрипт создать не может. Окно можно повесить на
кнопку джойстика — команда `FlyWithLua/x_announcer/toggle_window`.

При обновлении заменяйте файлы, но оставляйте свой `config.ini`.

## Звуковая библиотека

Путь задаётся в окне на вкладке **Library**. Структура — как у MSFS-версии:

```
<библиотека>/
├── Default/                       ← запасной пак, если для а/к файла нет
│   ├── SafetyBriefing.ogg
│   └── en-us/AfterLanding.ogg     ← необязательная языковая подпапка
├── AFL/
│   ├── BoardingWelcome.ogg
│   ├── AfterTakeoff[Night].ogg
│   ├── PreSafetyBriefing[A320].ogg
│   └── SafetyBriefing[2].ogg
└── BAW/…
```

Теги в имени файла:

| Тег | Смысл |
|---|---|
| `[A320]`, `[B738]`, `[CRJ9]` | только для этого типа ВС (сверяется с `acf_ICAO`) |
| `[Morning]` `[Afternoon]` `[Evening]` `[Night]` | только в это время суток (местное время борта) |
| `[1]`, `[2]`, … | варианты одной и той же реплики, выбирается случайный |
| `[Refueling]`, `[Deicing]` | распознаются, но в X-Plane пока не триггерятся — идут как запасной вариант |

Правило выбора: файл с подходящим тегом типа ВС и времени суток выигрывает у
файла без тегов; файл с **чужим** тегом (`[A321]` на A320) не играется никогда.
Если в паке авиакомпании реплики нет — берётся `Default`.

Поддерживаемые события: `BoardingWelcome`, `BoardingWelcomePilot`,
`BoardingStarted`, `BoardingMusic`, `BoardingComplete`, `DepartureDelayed`,
`ArmDoors`, `PreSafetyBriefing`, `SafetyBriefing`, `CabinDimTakeoff`,
`CrewSeatsTakeoff`, `CallCabinSecureTakeoff`, `AfterTakeoff`, `TopOfClimbPilot`,
`FastenSeatbelt`, `Turbulence`, `TopOfDescentPilot`, `DescentSeatbelts`,
`CabinDimLanding`, `BeforeLanding`, `CrewSeatsLanding`, `CallCabinSecureLanding`,
`AfterLanding`, `AfterLandingMusic`, `DisarmDoors`, `DisembarkStarted`,
`LandingGreat`, `LandingTerrible`, `CabinNoise`.

## Определение авиакомпании

1. **Вручную** — выбор пака в списке на вкладке Library (список — то, что
   реально лежит в библиотеке).
2. **Из SimBrief** — запросить свой последний план полёта и взять
   авиакомпанию оттуда. Само ничего не применяется: окно показывает позывной,
   маршрут, борт и **возраст плана**, и ждёт вашего решения. Возраст здесь
   главное — типичная ошибка в том, чтобы загрузиться в симулятор, не
   перестроив план, поэтому строка краснеет, когда плану больше трёх часов.
3. **Автоматически** — по пути ливреи (`acf_livery_path`), бортовому номеру,
   имени файла ВС и его описанию. Строка ищется по справочнику из 5774
   авиакомпаний (OpenFlights) плюс словарь частых написаний.
4. Ничего не нашли — `Default`.

Порядок сопоставления: сначала целые слова, потом название, склеенное с чем-то
ещё, потом укороченная форма официального названия, и только в последнюю
очередь голый код ICAO, стоящий отдельным словом. Порядок важен, потому что
названия папок ливрей полны строк, совпадающих с настоящими кодами ICAO:
`Thai Airways HS-TXS` не должен стать TXS, `Air China` — AIR, а
`Red Wings Airlines RA-73329` — RED.

Узнать авиакомпанию и иметь для неё пак — разные вещи. Если ливрея говорит
«S7», а пака S7 нет, окно так и пишет: `no pack for SBI - playing Default`,
вместо того чтобы делать вид, что ничего не распозналось.

На вкладке Flight видно, что именно сработало
(«livery (name): [CFMLEAP] S7 AIRLINES RA-73466»).

## Что и когда играет

| Событие | Условие в X-Plane |
|---|---|
| BoardingWelcome | на земле, двигатели выключены, маяк выключен, включено питание/огни. Повтор каждые N секунд (по умолчанию 300) |
| BoardingMusic | фоном между приветствиями (галка «Boarding music»), на отдельной шине, приглушается под объявления. Стоп — маяк или запуск двигателя |
| CabinNoise | шум салона в полёте (галка «Cabin ambience»), независимо от музыки посадки; выключается на земле |
| AfterLandingMusic | фон во время высадки, до сброса цикла |
| BoardingComplete | включён маяк или запущен двигатель |
| ArmDoors | двигатель работает / начали движение |
| PreSafetyBriefing → SafetyBriefing | последовательно, после ArmDoors |
| CabinDimTakeoff | ночь + брифинг закончился (+10 с) |
| CrewSeatsTakeoff | на земле, двигатели работают, включены стробы или посадочные фары |
| CallCabinSecureTakeoff | через 5 с после того, как CrewSeatsTakeoff доиграл |
| AfterTakeoff | в воздухе, выше 3000 ft AGL (или 150 с после отрыва) |
| TopOfClimbPilot | выше 15 000 ft, вертикальная < 350 fpm 25 с подряд |
| FastenSeatbelt / Turbulence | табло «пристегнуть ремни» включилось в полёте (пауза 180 с между срабатываниями). Turbulence — если перед этим была болтанка по перегрузке |
| TopOfDescentPilot | снижение ≥ 500 fpm выше 20 000 ft, 25 с подряд |
| DescentSeatbelts | ниже 10 000 ft на снижении |
| CabinDimLanding | ночь + ниже 10 000 ft |
| BeforeLanding | ниже 5000 ft AGL на снижении |
| CrewSeatsLanding | ниже 3000 ft AGL на снижении |
| CallCabinSecureLanding | через 10 с после CrewSeatsLanding |
| LandingGreat / LandingTerrible | по вертикальной скорости в момент касания (< 180 fpm — мягко, > 400 fpm — жёстко) |
| AfterLanding | на земле, путевая < 60 узлов |
| DisarmDoors | двигатели выключены и борт стоит: либо стояночный тормоз, либо путевая < 1 узла |
| DisembarkStarted | после DisarmDoors, маяк выключен → через 2 минуты цикл сбрасывается под следующий рейс |

Табло ремней читается из первого найденного датарефа (проверено по бинарникам
самих бортов):

| Борт | Датареф | «Горит» |
|---|---|---|
| ToLiss A320 | `AirbusFBW/SeatBeltSignsOn` | 1 |
| 737NG Series V2 | `b737ng/equipment/alerts/crew/cabin/CRW_seatbelts_on` | 1 |
| Rotate MD-11 | `Rotate/aircraft/controls/seatbelts_lts` | 1 |
| Zibo 737 | `laminar/B738/toggle_switch/seatbelt_sign_pos` | 2 (0 OFF, 1 AUTO, 2 ON) |
| прочие | `sim/cockpit2/switches/fasten_seat_belts`, `sim/cockpit/...` | 1 |

Свой датареф можно вписать в настройках — на вкладке Flight видно, какой
используется и его текущее состояние.

Логотипных огней в самом X-Plane нет вообще (в `DataRefs.txt` такого датарефа
не существует), поэтому как признак «салон под посадку» используются питание и
навигационные/рулёжные огни, а логотипные — только если их даёт аддон
(`laminar/B738/toggle_switch/logo_light`, `Rotate/aircraft/controls/logo_lts`).

## Окно

- **Flight** — текущая фаза крупно, что играет сейчас с прогрессом, авиакомпания
  и как она определена, тип ВС, местное время, состояние табло ремней, лестница
  фаз (что уже прошло / где мы сейчас), кнопки: заглушить, пропустить реплику,
  начать посадку пассажиров, сбросить рейс.
- **Library** — путь к библиотеке, пересканирование, выбор авиакомпании и
  таблица событий: сколько файлов, откуда берётся (пак а/к или Default) и кнопка
  `play` для прослушивания прямо в симуляторе. У играющей реплики кнопка
  становится `stop`, плюс `stop playback` с таймером в шапке вкладки — оборвать
  можно откуда угодно, не доигрывая файл. Прослушивание не засчитывается рейсу:
  протестированная реплика прозвучит потом по своему триггеру.
- **Settings** — вид экранного виджета, громкости (объявления, музыка,
  приглушение), что играть, период повтора приветствия, SimBrief, шины FMOD,
  языковая подпапка, датареф табло ремней, масштаб текста окна (для VR).
- **Log** — что и почему сыграло; сюда же попадают сообщения «нет файла».

### Виджет фазы полёта

Полупрозрачная плашка поверх картинки симулятора: в какой мы фазе и чего
плагин ждёт для перехода к следующей. Нужна, чтобы не открывать панель ради
вопроса «почему в салоне тихо». Три плотности:

```
minimal   CRUISE  ->  Descent            medium   CRUISE
          waiting: below 11 000 ft                next  Descent
                                                  . below 11 000 ft   34000
full      done  Takeoff                           . descending        120 fpm
          done  Climb
          > now Cruise                   Точка — условие не выполнено,
                Descent                  зелёная v — выполнено. Пауза,
                Approach                 реплей и Mute выводятся поверх
          next  Descent                  всего красным.
          . below 11 000 ft   34000
```

По умолчанию выключен: включается галочкой **Pin this to the screen** под
лестницей фаз на вкладке Flight или **Show it over the sim** в начале вкладки
Settings — это один и тот же переключатель. Плотность, непрозрачность и
положение настраиваются, за край экрана виджет не уедет при любых отступах,
клики он не перехватывает — случайно попасть по нему вместо тумблера в кабине
нельзя. Рисуется через
модуль graphics, а не вторым окном ImGui, и это осознанно: FlyWithLua сам
вызывает `ImGui::Begin()` до передачи управления билдеру, а ImGui берёт цвет
фона окна именно там — то есть альфу фона окна ImGui из Lua задать нельзя.

Команды для назначения на кнопки:

| Команда | Что делает |
|---|---|
| `FlyWithLua/x_announcer/toggle_window` | показать/скрыть окно |
| `FlyWithLua/x_announcer/skip` | оборвать текущую реплику |
| `FlyWithLua/x_announcer/start_boarding` | начать посадку пассажиров |

## Что может остановить объявления

| Признак | Причина | Что делать |
|---|---|---|
| `muted` под названием фазы | нажата кнопка Mute announcer | нажать Un-mute |
| `clock frozen: paused` | симулятор на паузе — таймеры стоят, реплика не «промотается» | снять паузу |
| `clock frozen: replay` | идёт реплей, плагин замер целиком | выйти из реплея |
| `stopped after repeated errors` | 10 ошибок подряд в колбэке; плагин выключил себя, чтобы не уронить Lua-движок вместе с чужими скриптами | причина в Log, затем FlyWithLua → Reload all Lua scripts |
| `no sound file` в журнале | для реплики нет файла ни у авиакомпании, ни в Default | добавить файл в пак или в `Default` |
| в колонке Source стоит «-» | библиотека не найдена или путь неверный | вкладка Library → путь → Rescan |
| `path too long for FlyWithLua` | FlyWithLua копирует имя файла в буфер 250 байт и молча обрезает более длинные | перенести библиотеку ближе к корню диска |
| `FMOD sound slot limit reached` | занято 350 слотов из 400, которые есть у FlyWithLua | кнопка Reload sound files в настройках |
| тишина сразу после смены борта | при смене борта или ливреи номера звуков в FlyWithLua протухают | плагин сбрасывает их сам; вручную — Reload sound files |
| нет объявления про ремни | у борта не нашлось датарефа табло (`not available` на вкладке Flight) | вписать свой датареф в настройках |

Ускорение времени обрабатывается: фазы считаются в симуляторном времени, а
длительность реплик — в настенном, поэтому на 2x и 4x реплики не режутся.

## Настройки (config.ini)

Файл создаётся сам, каждый ключ прокомментирован по-русски. Правьте при
выключенном симуляторе либо меняйте в окне — оно переписывает файл само.

| Ключ | Смысл |
|---|---|
| `library` | папка со звуковыми паками |
| `language` | языковая подпапка внутри пака (`en-us`, `de-de`, `ru`) |
| `airline_mode` | `auto` или `manual` |
| `airline_manual` | код пака при `manual` |
| `announce_bus` / `music_bus` | шины FMOD, обязаны различаться |
| `volume` / `music_volume` / `duck` | громкости и глубина приглушения |
| `enabled` | `false` — объявления выключены целиком |
| `boarding_music` / `cabin_noise` | фоновая музыка при посадке / шум салона в полёте |
| `auto_boarding` | начинать посадку самому, без кнопки |
| `boarding_repeat` | секунд между повторами приветствия |
| `pilot_welcome` / `door_calls` / `night_dim` / `landing_reaction` | какие группы реплик играть |
| `seatbelt_dref` | свой датареф табло ремней |
| `window_scale` | масштаб текста в окне |
| `auto_find` | искать готовую папку `UA_Sounds`, если в `library` пусто |
| `music_max_loops` | сколько раз зацикливать фоновый трек |
| `simbrief_id` | Pilot ID или имя учётной записи SimBrief |
| `widget` / `widget_mode` | экранный виджет и его плотность (`minimal`/`medium`/`full`) |
| `widget_opacity` / `widget_x` / `widget_y` | непрозрачность подложки и положение виджета |

## Чего сознательно нет

- Наземных служб в духе GSX и SimBrief-таймингов вылета: в X-Plane нет того,
  за что можно зацепиться.
- Синтеза речи. Плагин играет готовые файлы.
- Русского интерфейса в окне: FlyWithLua рисует UI встроенным растровым
  шрифтом ImGui, кириллицы в нём нет, а подключить свой шрифт из Lua нельзя.
  Поэтому по-русски — этот файл, `spravka-ru.txt` и комментарии в `config.ini`.

## Разработка

Плагин проверяется офлайн, без запуска симулятора: симулятор, FMOD, файловая
система и ImGui подменяются заглушками, а целые рейсы «пролетаются» на
ускоренном времени.

```bash
pip install lupa
python tests/sim_test.py "D:\UA_Sounds"
```

88 проверок: машина фаз, очередь звука, пауза и ускорение времени, круговорот
конфига, определение авиакомпании на настоящих названиях папок ливрей, разбор
ответа SimBrief, виджет фазы полёта и все режимы отказа, которые могут
заставить плагин замолчать.
